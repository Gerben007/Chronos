# Chronos

Self-hosted, bilingual (English + Afrikaans) interactive timeline of biblical
history with parallel lanes for Egypt, Rome, and other civilisations. Each
entry is a hub for curated learning resources auto-classified by Claude
Haiku from files dropped into Nextcloud.

**Status:** Phase 1 scaffold. No application code yet.

- See `PLAN.md` for the architecture and 17 locked decisions.
- See `docs/design-brief.md` and `docs/design-tokens.md` for the visual language.
- See `docs/development.md` for local-dev setup.
- See `SECURITY.md` for the threat model and disclosure process.
